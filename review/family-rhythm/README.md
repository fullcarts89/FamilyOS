# Family Rhythm redesign: review images

Screenshots and recordings of `redesign/family-rhythm` at `d284091`, for the pull request that
proposes it for `main`. They show the invented Rivera household from `pnpm demo:seed`, never real
data. Kept on this branch so review images don't end up in `main`.

- `screens/`: every screen at desktop (1440×900) and phone (390×844, 2×). `*-full` is the whole
  scrolling page.
- `recordings/`: the seven acceptance interactions, desktop and phone, plus three extras. They come
  from the Playwright end-to-end journeys in `e2e/`.
