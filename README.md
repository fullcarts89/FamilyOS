# FamilyOS

A shared household agent: adults in one home capture tasks, approve what the agent sends to vendors, and keep a verified record of what got done.

Proprietary and confidential. All rights reserved.

**Status:** Phase A (research, architecture and plan). No application code yet. The build is gated on founder approval of `docs/decisions/founder-gate-0.md`.
